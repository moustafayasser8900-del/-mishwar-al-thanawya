# 📚 مِشوار الثانوية (Mishwar Al-Thanawya)

منصة تعليمية ويب متكاملة ومجانية بالكامل مصممة خصيصاً لمساعدة طلاب الثانوية العامة والبكالوريا في تنظيم دراستهم والحصول على المذكرات والملخصات.

### 🌟 مميزات المنصة:
- 📖 مكتبة شاملة للكتب والمذكرات والملخصات.
- 📅 خطة يومية ومنظم مهام المذاكرة.
- 🤖 مساعد ذكي (زكي) للإجابة على الأسئلة الدراسية.
- 🎨 تصميم عصري فاخر (Dark Mode مع لمسات ذهبية).

### 👨‍💻 المطور:
تم التطوير بواسطة **مصطفى ياسر (Moustafa Yasser)**.
